# 🎬 MovieMind — Content-Based Movie Recommendation System

**Discover movies you'll love based on what you already enjoy.**

MovieMind is a production-ready, content-based movie recommendation web
application built with Python and Streamlit, powered by the TMDB 5000
dataset, and designed for deployment on **Railway**.

---

## 1. Project Overview

MovieMind lets a user pick a movie they like and instantly returns the
5 most similar movies, complete with posters fetched live from the TMDB
API. Recommendations are generated using a content-based machine
learning approach — no user ratings required.

---

## 2. Features

- Content-based recommendations using overview, genres, keywords, cast, and director
- Precomputed similarity model (fast, no runtime retraining)
- Live movie posters from the TMDB API with graceful fallbacks
- Dark, cinematic, responsive Streamlit UI
- Home / Movie Recommender / About sections
- Robust error handling for missing files, bad titles, and network issues
- Environment-variable based secrets (no hard-coded API keys)
- Ready to deploy on Railway with a dynamic `$PORT`

- `tmdb_5000_credits.csv`

You can download both files from Kaggle:
https://www.kaggle.com/datasets/tmdb/tmdb-movie-metadata

Place both CSV files inside the `data/` folder before running preprocessing.

## 5. Machine Learning Approach

MovieMind uses **content-based filtering**:

1. For each movie, the overview, genres, keywords, top 3 cast members,
   and director are combined into a single text field called `tags`.
2. This text is converted into numerical vectors.
3. The similarity between every pair of movies is calculated.
4. When a user selects a movie, the 5 movies with the highest similarity
   score (excluding the movie itself) are returned.

### CountVectorizer Explanation

`CountVectorizer` converts each movie's `tags` text into a vector of
word counts, limited to the 5000 most frequent terms and excluding
common English stop words (like "the", "and", "is"). Movies that share
more of the same significant words end up with vectors that point in
similar directions.

```python
CountVectorizer(max_features=5000, stop_words="english")
```

### Cosine Similarity Explanation

`Cosine Similarity` measures the angle between two vectors rather than
their magnitude, which makes it well-suited for comparing text-based
feature vectors of different lengths. A score of `1.0` means two movies
are identical in their tag composition; a score closer to `0` means
they share very little in common.

## 7. Local Installation

Clone the repository and move into the project folder:

```bash
git clone https://github.com/your-username/movie-recommender.git
cd movie-recommender
```

Create a virtual environment (recommended):

```bash
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## 8. Dataset Setup

Download `tmdb_5000_movies.csv` and `tmdb_5000_credits.csv` and place
them inside the `data/` folder as shown in the project structure above.

---

## 9. TMDB API Key Setup

1. Create a free account at https://www.themoviedb.org/
2. Go to **Settings → API** and request an API key (v3 auth).
3. Create a `.env` file in the project root (copy `.env.example`):

```bash
cp .env.example .env
```

4. Open `.env` and add your real key:

```
TMDB_API_KEY=your_actual_api_key_here
```

**Never commit your real `.env` file to GitHub.** It is already listed
in `.gitignore`.

---

## 10. Running Preprocessing

Generate the trained model files:

```bash
python preprocess.py
```

This reads the CSV files from `data/`, cleans and merges them, trains
the CountVectorizer + Cosine Similarity model, and saves
`models/movie_dict.pkl` and `models/similarity.pkl`. You only need to
run this once (or whenever the dataset changes).

---

## 11. Running Streamlit Locally

```bash
streamlit run app.py
```

Open the URL shown in your terminal (typically `http://localhost:8501`).

## 13. Railway Deployment

1. Push your project to a GitHub repository (see above).
2. Go to https://railway.app/ and log in.
3. Click **New Project → Deploy from GitHub repo**.
4. Select your `movie-recommender` repository.
5. Railway will detect `requirements.txt` and `Procfile` / `railway.toml`
   and automatically build the project using Nixpacks.
6. Add your environment variable (see section 14 below).
7. Railway will start the app using the production start command:

   ```
   streamlit run app.py --server.address=0.0.0.0 --server.port=$PORT
   ```

8. Once the deployment finishes, open the generated Railway domain
   (e.g. `https://movie-recommender-production.up.railway.app`).

## 15. Troubleshooting

| Issue                                             | Solution |
|----------------------------------------------------|----------|
| `Model files not found` error in the app            | Run `python preprocess.py` locally and make sure `models/movie_dict.pkl` and `models/similarity.pkl` are committed to your repository. |
| Posters not loading / placeholder shown             | Check that `TMDB_API_KEY` is set correctly (locally in `.env`, on Railway in the Variables panel). |
| App doesn't start on Railway                        | Confirm `Procfile` and `railway.toml` use `$PORT` and `--server.address=0.0.0.0`, not a hard-coded port. |
| `data/tmdb_5000_movies.csv not found`               | Download the dataset from Kaggle and place both CSVs inside `data/`. |
| Build fails on Railway                              | Double-check `requirements.txt` versions are compatible with Python 3.11. |
| Selected movie has no recommendations                | The title may not exist in the dataset — pick a title directly from the dropdown to avoid typos. |
